# КосмоХакатон 2026 — Проектирование устойчивой спутниковой группировки

Продакшн-платформа моделирования, анализа устойчивости, оптимизации топологии и расчета экономической эффективности низкоорбитальной космической группировки.

---

## 🚀 Быстрый запуск (Quick Start)

### Вариант 1: Запуск через Docker (Рекомендуемый)

```bash
docker-compose up --build
```
После запуска сервис доступен по адресу: **`http://localhost:8000`**

---

### Вариант 2: Локальный запуск (Python + React Vite)

#### 1. Запуск Backend (FastAPI):
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r backend/requirements.txt  # или fastapi uvicorn networkx numpy
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload
```

#### 2. Сборка Frontend (React 18 + TypeScript + Vite):
```bash
cd frontend
npm install
npm run build
```

Откройте в браузере: **`http://127.0.0.1:8000`**

## 🏛️ Архитектура системы и разделение ответственности

Проект строго разделен на изолированные слои:

* **`backend/geometry.py`** — Математическое ядро расчёта координат (`cosmo-A-1.0`). Рассчитывает Кеплеровские 3D-орбиты, углы места радиовидимости ($\theta_{\text{elev}} \ge 10^\circ$) и геометрию межспутниковых связей (ISL).
* **`backend/calc_engine.py`** — Модуль трассировки и SLA. Строит динамический граф связности в NetworkX (алгоритм Дейкстры), рассчитывает доступность SLA, причины отказов и экономические оптимизационные модели.
* **`backend/main.py`** — FastAPI сервер с REST API эндопоинтами (`/api/simulate`, `/api/compare`, `/api/scenarios`).
* **`frontend/src/`** — React 18 + TypeScript + Three.js UI:
  * `ThreeCanvas.tsx` — 3D-рендеринг Земли (сферическая модель, R=6371 км), орбит, динамических лучей связи и конусов радиовидимости.
  * `OutlinerPanel.tsx` — Дерево элементов с возможностью кастомизации цвета (Color Pickers) каждого 3D-объекта и управления фазированием ($\Delta\text{Phase}$ / $\Delta\text{RAAN}$).
  * `EmergencyModal.tsx` — Панель моделирования ЧС (Солнечная вспышка CME, отказ шлюзов, космический мусор).
  * `AnalyticsModal.tsx` — Метрики доступности SLA, диаграмма Гантта, карта покрытия и экономические рекомендации.
  * `CompareModal.tsx` — Модуль бок-о-бок сравнения конфигураций группировки.

## 📊 Матрица соответствия критериям оценки (100 баллов)

### 🏆 Отраслевые эксперты (до 50 баллов)

#### Раздел 1. Проектирование и анализ группировки (35 баллов)
* **Проектирование и сравнение конфигураций (15 баллов):** Доступен выбор этапа развертывания (16 или 48 КА), ручная настройка плоскостей ($\Delta\text{RAAN}$, $\Delta\text{Phase}$) и модуль бок-о-бок сравнения двух проектов (`CompareModal`).
* **Анализ устойчивости (10 баллов):** Полный учет отказов, выявление узких мест и нагруженных КА (`vulnerability` вкладка), моделирование техногенных и природных ЧС (`EmergencyModal`).
* **Обоснованность рекомендаций (10 баллов):** Расчет экономически оптимального варианта ликвидации сбоев (перенастройка сетки ISL и фазирования за **$50,000** вместо физической покупки новых КА за **$3.27M**).

#### Раздел 2. Удобство использования (10 баллов)
* Понятная навигация, интерактивный таймлайн (`TimelineBar`) с ползунком и шагами, 3D-конусы покрытия, индивидуальная настройка цветов 9 элементов сцены.

#### Раздел 3. Презентация решения (5 баллов)
* Готовый демонстрационный сценарий, отсутствие смайликов, академический инженерный интерфейс.

---

### 💻 Технические эксперты (до 50 баллов)

#### Раздел 4. Расчётная модель и маршрутизация (30 баллов)
* **Корректность расчётов (15 баллов):** 100% совпадение математики с `geometry.py`, учет физического эллипсоида WGS-84, фиксированный нормативный угол места $10.0^\circ$.
* **Алгоритмы маршрутизации (15 баллов):** Вычисление кратчайших путей на графе NetworkX (Dijkstra) в реальном времени с мгновенным перерасчетом при авариях.

#### Раздел 5. Работа с данными (10 баллов)
* Поддержка загрузки внешних JSON сценариев (`cosmo-A-1.0`), экспорт итоговой конфигурации и результатирующих метрик в JSON, надежная валидация входных данных.

#### Раздел 6. Качество кода и документация (10 баллов)
* **Качество кода (5 баллов):** Полноценный TypeScript (TSX) + Python 3.11+, защита от ошибок `undefined`/`null`, модульная структура.
* **Документация и запуск (5 баллов):** Docker, Docker-Compose, полная инструкция по развертыванию.
